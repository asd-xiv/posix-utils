# Migrate to v6

## `_delete_on_exit`

```diff
-# _delete_on_exit <path> [on-exit]
+# _delete_on_exit <dir>
 #
-# Delete <path> when the script exits, or when INT, TERM or HUP stops it. Run
-# the function <on-exit> first, with the exit code as its positional: the
-# code of the script on EXIT, 130 on INT, 143 on TERM, 129 on HUP. Replaces
-# the traps of EXIT, INT, TERM and HUP.
+# Delete the absolute folder <dir> when the script exits, or when INT, TERM or
+# HUP ends it. A function that a later _on_exit call registers runs first.
+#
+# A script calls it once. Create any other temporary folder inside <dir>, eg.
+# `mktemp -d "$_TEMP_DIR/part.XXXXXX"`.
 #
 # EXIT
-#   3   <on-exit> is not a function name
+#   3   A second call, or a <dir> that is not an absolute path
```

### It does not take a function anymore

```sh
# Before
_TEMP_DIR=$(_create_temp_dir sync)
_delete_on_exit "$_TEMP_DIR" _finish_sync

# After
_TEMP_DIR=$(_create_temp_dir sync)
_delete_on_exit "$_TEMP_DIR"
_on_exit _finish_sync
```

`_on_exit` registers any number of functions, so `_delete_on_exit`,
`_set_title_until_exit` and your own cleanup function no longer replace each
other's traps.

### It takes only one folder per script

```sh
# Before
_TEMP_DIR=$(_create_temp_dir sync)
_delete_on_exit "$_TEMP_DIR"
_PART_DIR=$(_create_temp_dir sync-part)
_delete_on_exit "$_PART_DIR"

# After
_TEMP_DIR=$(_create_temp_dir sync)
_delete_on_exit "$_TEMP_DIR"
_PART_DIR=$(mktemp -d "$_TEMP_DIR/part.XXXXXX")
```

In v5, the second call replaced the traps of the first, so the first folder
stayed behind.

### It takes only an absolute path

```sh
# Before
mkdir build
_delete_on_exit build

# After
mkdir build
_delete_on_exit "$PWD/build"
```

After a `cd`, a relative path names another folder, so `rm -rf` on exit would
delete the wrong one.

## `terminal.sh`

```diff
-#   Needs no other file of bin/lib.
+#   Needs log.sh, os.sh. A script sources them before this file.
```

### It needs `os.sh` now

```sh
# Before
. "$_SCRIPT_DIR/../lib/log.sh"
. "$_SCRIPT_DIR/../lib/terminal.sh"

# After
. "$_SCRIPT_DIR/../lib/log.sh"
. "$_SCRIPT_DIR/../lib/os.sh"
. "$_SCRIPT_DIR/../lib/terminal.sh"
```

`_set_title_until_exit` calls `_on_exit` of `os.sh` to restore the title on
exit.
